# Mesut IPTV — Flutter project

مشغل IPTV يعتمد على بيانات دخول Xtream Codes التي يقدمها المستخدم من مزود يملك حق الوصول إلى محتواه.

## المتطلبات
- Flutter stable وDart المتوافقان مع `pubspec.yaml`.
- Java 17 لبناء Android عبر GitHub Actions.
- اتصال إنترنت للوصول إلى مستودعات Flutter وPub.

## البناء عبر GitHub Actions
1. ارفع محتويات هذا المجلد إلى جذر المستودع، مع الحفاظ على مجلد `.github/workflows`.
2. افتح تبويب **Actions**.
3. شغّل **Mesut IPTV Android Build** بواسطة **Run workflow** أو ادفع commit جديداً إلى `main`.
4. بعد نجاح المهمة، افتح صفحة التشغيل ونزّل artifact باسم `mesut-iptv-android-release-candidate`.
5. يحتوي artifact على APK للاختبار وAAB غير موقّع ما لم تتم إضافة إعداد توقيع إصدار منفصل.

## حماية بيانات الدخول
- نُقلت كلمات مرور Xtream ورمز PIN إلى `flutter_secure_storage`.
- عند أول تشغيل بعد التحديث، يحاول التطبيق ترحيل بيانات الحسابات والـPIN القديمة من SharedPreferences إلى التخزين الآمن، ثم يحذف مفاتيحها القديمة.
- لا تحذف التطبيق أو بياناته قبل التأكد من نجاح التحديث والترحيل على جهاز تجريبي.

## إعلانات AdMob
- وضع الاختبار مفعّل افتراضياً في `lib/ads.dart`.
- لا تستخدم النقرات على الإعلانات التجريبية كدليل على الإيرادات.
- لا تغيّر `kTestAds` إلى `false` إلا بعد إعداد موافقة الخصوصية UMP، وإكمال مراجعة AdMob، واختبار نسخة الإنتاج بمعرّفات الوحدات الحقيقية.
- لا تعرض الإعلانات فوق الفيديو أو بطريقة تؤدي إلى النقر غير المقصود.

## حدود هذه الحزمة
هذه حزمة مرشح تطوير وليست شهادة جاهزية نشر. ما زال يلزم استكمال واختبار: دليل EPG شبكي كامل، البحث الموحد بين كل الأقسام، واجهة اختيار مسارات الصوت والترجمة في المشغل، اختبارات الريموت على Android TV/Fire TV، شاشة موافقة UMP، سياسة خصوصية منشورة، مفتاح توقيع AAB، واختبار أجهزة حقيقية.

## حقوق المحتوى
Mesut IPTV مشغل فقط. على المستخدم إدخال بيانات خدمة مرخّصة يملك حق استخدامها. لا تتضمن الحزمة قوائم قنوات أو أفلام أو بيانات دخول أو روابط بث جاهزة.
