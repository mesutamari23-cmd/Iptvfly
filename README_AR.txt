Mesut IPTV - Patch files

هذا الأرشيف يحتوي ملفات استبدال، وليس المشروع الكامل.

الخطوات:
1. في GitHub افتح المستودع Iptvfly ثم مجلد lib.
2. استبدل lib/main.dart بالملف الموجود في هذا الأرشيف.
3. استبدل lib/store.dart بالملف الموجود في هذا الأرشيف.
4. افتح lib/player_screen.dart وطبّق التغيير الموضح في PLAYER_SCREEN_CHANGE.txt.
5. احفظ التغييرات ثم شغّل GitHub Actions.

ملاحظات مهمة:
- هذا تعديل لتقليل احتمال فشل بدء التشغيل وإظهار تفاصيل الخطأ على الشاشة.
- عند تعذر Android Keystore، يستخدم Store نسخة احتياطية محلية غير مشفرة للحسابات والـ PIN. التخزين الآمن يظل المسار الأساسي. لا تستخدم النسخة الاحتياطية غير المشفرة على جهاز مشترك.
- لم يتم تشغيل Flutter build أو اختبار APK على جهاز فعلي في بيئة إعداد هذه الملفات؛ لذلك لا تعتبر النسخة مؤكدة قبل نجاح GitHub Actions وتجربتها على الهاتف.
- إذا ظهر خطأ على شاشة التشخيص، أرسل صورة الخطأ.
